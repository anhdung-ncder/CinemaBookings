# CinemaBookings

## Giới thiệu
CinemaBookings là dự án nhóm xây dựng ứng dụng đặt vé xem phim bằng C++ theo phương pháp lập trình hướng đối tượng (OOP).

## Công nghệ
- C++
- C++17
- CMake
- Git và GitHub

## Cấu trúc dự án
- `include/`: Các tệp header của chương trình.
- `src/`: Mã nguồn triển khai.
- `tests/`: Các tệp kiểm thử.
- `data/`: Dữ liệu phục vụ ứng dụng.
- `docs/`: Tài liệu phân tích và thiết kế.
- `CinemaError.h`: Khung xử lý ngoại lệ của ứng dụng.

## Biên dịch
Dự án sử dụng CMake và yêu cầu trình biên dịch hỗ trợ C++17.

## Trạng thái
Đang xây dựng khung dự án ban đầu.
